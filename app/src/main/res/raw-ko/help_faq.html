AdAway Community란 무엇인가요?

AdAway Community는 Android용 오픈 소스 광고 차단 앱인 AdAway를 커뮤니티가 유지 관리하는 비공식 포크입니다. 모든 앱에서 시스템 전체로 광고와 트래커를 차단하며, 계정이 필요 없고 자체 광고도 없습니다. 이 포크는 최신 Android 버전과 제조사 ROM에서도 앱이 안정적으로 작동하도록 유지하는 데 중점을 둡니다.

광고는 어떻게 차단하나요?

AdAway는 두 가지 모드 중 하나로 작동합니다.

VPN 모드(루트 불필요): AdAway가 기기 안에서 로컬 VPN을 실행하며, 이 VPN은 트래픽을 어디로도 보내지 않습니다. DNS 요청만 살펴보고 광고 및 트래커 호스트 이름으로 향하는 요청은 차단하며, 나머지는 그대로 통과시킵니다. 어떤 데이터도 기기 밖으로 나가지 않습니다.

루트 모드: 기기가 루팅되어 있다면 AdAway가 hosts 파일을 /system/etc/hosts에 대신 기록할 수 있습니다. 원하지 않는 호스트 이름을 127.0.0.1로 연결하여 사용자의 기기 자신으로 향하게 합니다. 최신 Android에서는 systemless hosts 모듈(예: Magisk)이 필요합니다.

VPN은 어떤 DNS 서버를 사용하나요?

VPN 모드에서 차단되지 않은 호스트 이름은 설정 › VPN 기반 광고 차단 › DNS 서버에서 선택한 DNS 서버가 확인합니다.

네트워크 DNS 서버(기본값): Wi-Fi 또는 모바일 네트워크의 서버입니다. 네트워크가 AdAway에서 사용할 수 있는 서버를 제공하지 않으면 Cloudflare(1.1.1.1)를 대신 사용합니다.
사용자 지정 DNS 서버: 직접 입력한 IP 주소이며 쉼표로 구분합니다.
DNS over HTTPS: 요청을 암호화하여 Cloudflare, Google, Quad9 또는 직접 입력한 https:// 주소로 보내므로, 네트워크에서 내용을 읽거나 바꿀 수 없습니다.

세 가지 방식 모두 차단 기능은 똑같이 작동합니다. 암호화된 DNS를 유지하려면 AdAway를 우회하는 Android의 비공개 DNS 설정 대신 여기서 DNS over HTTPS를 사용하세요.

호스트 이름을 차단, 허용 또는 리디렉션하려면 어떻게 하나요?

홈 화면에서 세 가지 목록을 관리할 수 있습니다.

차단됨: 차단할 호스트 이름입니다(광고 및 트래커).
허용됨: 소스에 포함되어 있더라도 절대 차단하지 않을 예외입니다.
리디렉션됨: 특정 IP 주소로 연결할 호스트 이름입니다.

홈 화면에서 DNS 로그를 열면 앱이 요청하는 호스트 이름을 실시간으로 확인할 수 있으며, 그 자리에서 바로 차단하거나 허용할 수도 있습니다.

목록을 변경한 뒤 Android를 다시 시작해야 하나요?

아니요. AdAway는 변경 사항을 바로 적용하지만, 이미 열려 있던 앱은 이전 연결과 자체 캐시를 계속 사용할 수 있습니다. 앱을 완전히 종료하고(Android 설정의 앱 정보에서 강제 종료), 그래도 광고가 표시되면 캐시를 삭제하세요. Android 재시작은 루트 모드에서 Magisk의 systemless hosts 모듈을 켠 직후 한 번만 필요합니다.

hosts 소스는 어디서 더 찾을 수 있나요?

AdAway에는 무난한 기본 소스가 포함되어 있습니다. 더 필요하다면 커뮤니티가 관리하는 추가 hosts 소스 목록을 참고하세요. 매우 크거나 서로 겹치는 목록은 앱이 작동하지 않게 만드는 오탐을 일으킬 수 있으므로, 소스는 꼭 필요한 만큼만 추가하세요.

이 포크는 왜 만들어졌나요?

AdAway는 오랜 역사를 가진 훌륭한 프로젝트이지만, 한동안 원본 프로젝트의 릴리스와 검토 활동이 뜸했습니다. 최신 Android 버전과 제조사 ROM에서 VPN 모드의 안정성에 영향을 주는 문제를 포함해, 일부 버그 수정과 풀 리퀘스트가 오랫동안 열려 있었습니다. 이 포크는 검증된 개선 사항이 쓰이지 못한 채 남아 있게 두는 대신, 커뮤니티가 관리하는 수정 사항으로 프로젝트를 계속 사용할 수 있게 하려고 만들어졌습니다.

버그를 신고하거나 변경을 제안하려면 어떻게 하나요?

이 포크의 이슈 트래커에 이슈를 등록해 주세요: https://github.com/Victor-root/AdAway-Community/issues. VPN 문제를 신고할 때는 진단 로그(문제 해결 탭 참고)가 큰 도움이 됩니다.
