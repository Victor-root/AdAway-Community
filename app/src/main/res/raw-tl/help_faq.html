Ano ang AdAway Community?

Ang AdAway Community ay isang hindi opisyal na fork ng AdAway na pinapanatili ng komunidad, ang open-source na ad blocker para sa Android. Bina-block nito ang mga ad at tracker sa buong system, para sa bawat app, nang walang account at walang sariling ad. Nakatuon ang fork na ito sa pagpapanatiling maaasahang gumagana ang app sa mga makabagong bersyon ng Android at sa mga OEM ROM.

Paano ito nagba-block ng mga ad?

Gumagana ang AdAway sa isa sa dalawang mode:

VPN mode (hindi kailangan ng root): nagpapatakbo ang AdAway ng lokal na VPN sa mismong device na hindi kailanman nagpapadala ng iyong trapiko kahit saan. Mga DNS request lang ang sinusuri nito at ibinabasura ang mga tumutukoy sa mga hostname ng ad at tracker, habang pinapadaan ang lahat ng iba pa. Walang lumalabas sa iyong device.

Root mode: kung naka-root ang iyong device, maaari ring magsulat ang AdAway ng hosts file sa /system/etc/hosts, na nagma-map sa 127.0.0.1 ng mga hindi gustong hostname para mag-resolve ang mga ito sa sarili mong device. Sa mga bagong bersyon ng Android, kailangan ng systemless hosts module (hal. Magisk).

Aling mga DNS server ang ginagamit ng VPN?

Sa VPN mode, ang mga hostname na hindi naka-block ay nire-resolve ng mga DNS server na pipiliin mo sa Mga Kagustuhan › Ad blocker na batay sa VPN › Mga DNS server:

Mga DNS server ng network (default): ang mga server ng iyong Wi-Fi o mobile network. Kung walang ibinigay na magagamit ng AdAway ang network, babalik ito sa Cloudflare (1.1.1.1).
Mga custom na DNS server: ang mga IP address na ilalagay mo, pinaghihiwalay ng kuwit.
DNS over HTTPS: naka-encrypt ang mga kahilingan at ipinapadala sa Cloudflare, Google, Quad9 o sa https:// address na ilalagay mo, kaya hindi ito mababasa o mababago ng iyong network.

Pareho ang pagkakagana ng pag-block sa tatlo. Para manatiling encrypted ang DNS, gamitin dito ang DNS over HTTPS sa halip na ang setting ng Android na Pribadong DNS, na nilalampasan ang AdAway.

Paano ako magba-block, magpapahintulot o magre-redirect ng hostname?

Mula sa home screen, may tatlong listahan kang mapamamahalaan:

Naka-block: mga hostname na dapat i-block (mga ad at tracker).
Pinapayagan: mga exception na ayaw mong ma-block kailanman, kahit nakalista ang mga ito sa isang pinagmulan.
Naka-redirect: mga hostname na gusto mong ituro sa isang partikular na IP address.

Maaari mo ring buksan ang Log ng DNS mula sa home screen para makita sa real time kung anong mga hostname ang tinatanong ng mga app, pagkatapos ay i-block o payagan ang mga ito mismo roon.

Kailangan ko bang i-restart ang Android pagkatapos baguhin ang aking mga listahan?

Hindi. Agad na ilalapat ng AdAway ang pagbabago, pero maaaring patuloy na gamitin ng isang app na nakabukas na ang mga dati nitong koneksyon at ang sarili nitong cache. Isara ito nang ganap (Sapilitang ihinto sa mga setting ng Android ng app), at i-clear ang cache nito kung may lumalabas pa ring ad. Kailangan lang ng restart ng Android nang isang beses sa root mode, pagkatapos i-enable ang systemless hosts module ng Magisk.

Saan ako makakahanap ng mas maraming pinagmulan ng hosts?

May makatwirang mga default ang AdAway. Kung gusto mo pa ng iba, tingnan ang listahan ng karagdagang pinagmulan ng hosts na pinapanatili ng komunidad. Magdagdag ng mga pinagmulan nang katamtaman lang, dahil ang napakalaki o magkakapatong na mga listahan ay maaaring magdulot ng mga false positive na sumisira sa mga app.

Bakit umiiral ang fork na ito?

Isang mahusay na proyekto ang AdAway na may mahabang kasaysayan, pero matagal nang limitado ang aktibidad ng upstream sa mga release at review. May ilang bug fix at pull request na matagal na nanatiling bukas, kabilang ang mga isyung nakakaapekto sa katatagan ng VPN mode sa mga bagong bersyon ng Android at sa mga OEM ROM. Umiiral ang fork na ito para manatiling magagamit ang proyekto sa tulong ng mga ayos na pinapanatili ng komunidad, sa halip na hayaang hindi magamit ang mga pagpapabuting nasubukan na.

Paano ako mag-uulat ng bug o magmumungkahi ng pagbabago?

Magbukas ng issue sa tracker ng fork: https://github.com/Victor-root/AdAway-Community/issues. Malaking tulong ang log ng diagnostic (tingnan ang tab na Mga Problema) kapag nag-uulat ng mga isyu sa VPN.
