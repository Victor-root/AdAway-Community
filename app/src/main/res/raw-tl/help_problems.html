Kusang nag-o-off ang VPN

Halos palaging ang system ang pumapatay sa VPN service para makatipid ng baterya, hindi pag-crash. Karaniwan ito sa mga OEM ROM na may agresibong power management (ColorOS/Oppo, MIUI/Xiaomi, EMUI/Huawei, OneUI/Samsung, at iba pa).

Sa mga setting ng Android, hanapin ang AdAway at: itakda ang pag-optimize ng baterya sa Walang restriction (o Huwag i-optimize), payagan ang autostart/auto-launch kung mayroon nito ang iyong ROM, at i-lock ang AdAway sa listahan ng mga kamakailang app para hindi ito mai-swipe palayo. Tiyakin din na naka-on ang I-enable sa pagsisimula sa mga kagustuhan ng VPN ng AdAway.

Walang internet o mabagal ang pag-browse pagkatapos lumipat sa pagitan ng Wi-Fi at mobile

Kapag nagbago ang aktibong network, kailangang buuin muli ang tunnel para ma-resolve ang DNS mula sa bagong network. Kung nananatiling sira ang pag-browse, buksan ang Mga Kagustuhan › Ad blocker na batay sa VPN › I-reset ang VPN para buuin muli mula sa simula ang koneksyon. Kung paulit-ulit itong nangyayari, mag-capture ng log ng diagnostic (sa ibaba) at iulat ito.

Paano ako mag-e-export ng log ng diagnostic?

Buksan ang Mga Kagustuhan › Ad blocker na batay sa VPN › Log ng diagnostic. Nire-record nito ang mga kamakailang error at event ng VPN (paglipat ng network, muling pagkonekta, pagkabigo), hindi ang history ng pag-browse mo, mga teknikal na event lang. Mananatili itong walang laman hanggang hindi mo ino-on ang I-record ang log ng diagnostic sa mismong itaas. Gamitin ang Kopyahin o Ibahagi para ipadala ito kapag nag-uulat ng problema. Tip: I-clear muna ito, saka ulitin ang isyu, para nakatuon ang log.

Nagpapakita pa rin ng mga ad ang Chrome

Maaaring gamitin ng Chrome ang sarili nitong Secure DNS (DNS-over-HTTPS), na nilalampasan ang AdAway. Sa Chrome, buksan ang Mga Setting › Privacy at seguridad › Gumamit ng secure DNS at i-off ito. Ganoon din para sa anumang setting na Pribadong DNS ng app o ng system. Sa VPN mode, kaya ng AdAway na i-encrypt mismo ang DNS: tingnan ang Aling mga DNS server ang ginagamit ng VPN? sa FAQ.

May mga ad pa ring nakakalusot, o may app na nagpapakita pa rin ng mga ad

Maaaring wala sa iyong mga pinagmulan ang isang hostname, o isinasama ng app ang mga ad nito kaya walang kahilingang ginagawa. Buksan ang Log ng DNS mula sa home screen para makita kung ano ang tinatanong ng app, idagdag ang mga kahina-hinalang hostname sa iyong listahan ng Naka-block, at tiyaking walang masisira. May mga app ding nagka-cache ng mga ad pagkatapos i-download ang mga ito, kaya makakatulong ang pag-clear ng cache ng app na iyon sa mga setting ng Android.

Tumigil sa paggana ang isang app pagkatapos i-enable ang AdAway

Tumatangging gumana ang ilang app kapag naka-block ang hostname na kailangan nila. Gamitin ang Log ng DNS para malaman kung aling hostname ang kailangan ng app, idagdag ito sa iyong listahan ng Pinapayagan, at dapat gumana na ulit ang app. Nakalista dito ang mga kilalang problematikong app.

Hindi nailalapat ang hosts file (root mode)

Read-only na /system partition ang ginagamit ng mga bagong bersyon ng Android, kaya hindi direktang makakasulat doon ang AdAway. Kung gumagamit ka ng Magisk, i-enable ang systemless hosts module, mag-reboot, at ilapat ulit. Kung hindi ka gumagamit ng root, lumipat na lang sa VPN mode, na hindi nangangailangan ng anumang pagbabago sa system.
