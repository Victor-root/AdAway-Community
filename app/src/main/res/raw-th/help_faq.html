AdAway Community คืออะไร

AdAway Community คือฟอร์กของ AdAway ที่ชุมชนช่วยกันดูแล ไม่ใช่ฉบับทางการ AdAway เป็นตัวบล็อกโฆษณาโอเพนซอร์สสำหรับ Android ที่บล็อกโฆษณาและตัวติดตามทั้งระบบ ครอบคลุมทุกแอป โดยไม่ต้องมีบัญชีและไม่มีโฆษณาของตัวเอง ฟอร์กนี้มุ่งเน้นให้แอปทำงานได้อย่างเสถียรบน Android เวอร์ชันใหม่ ๆ และ ROM ของผู้ผลิตโทรศัพท์

บล็อกโฆษณาอย่างไร

AdAway ทำงานได้ 2 โหมด

โหมด VPN (ไม่ต้องมี root): AdAway เปิด VPN ภายในเครื่องที่ไม่ส่งข้อมูลของคุณไปที่ใดเลย โดยจะตรวจดูเฉพาะคำขอ DNS และทิ้งคำขอที่ชี้ไปยังชื่อโฮสต์ของโฆษณาและตัวติดตาม ส่วนที่เหลือปล่อยผ่านตามปกติ ไม่มีข้อมูลใดออกจากอุปกรณ์ของคุณ

โหมด root: หากอุปกรณ์ของคุณเปิดสิทธิ์ root AdAway สามารถเขียนไฟล์ hostsไปที่ /system/etc/hosts แทนได้ โดยจับคู่ชื่อโฮสต์ที่ไม่ต้องการเข้ากับ 127.0.0.1 เพื่อให้ชี้กลับมาที่อุปกรณ์ของคุณเอง บน Android เวอร์ชันใหม่ ๆ ต้องใช้โมดูล systemless hosts (เช่น Magisk)

VPN ใช้เซิร์ฟเวอร์ DNS ตัวไหน

ในโหมด VPN ชื่อโฮสต์ที่ไม่ถูกบล็อกจะถูกค้นหาโดยเซิร์ฟเวอร์ DNS ที่คุณเลือกใน การตั้งค่า › ตัวบล็อกโฆษณาแบบ VPN › เซิร์ฟเวอร์ DNS:

เซิร์ฟเวอร์ DNS ของเครือข่าย (ค่าเริ่มต้น): เซิร์ฟเวอร์ของเครือข่าย Wi-Fi หรือเครือข่ายมือถือของคุณ หากเครือข่ายไม่มีเซิร์ฟเวอร์ที่ AdAway ใช้ได้ ระบบจะสลับไปใช้ Cloudflare (1.1.1.1)
เซิร์ฟเวอร์ DNS แบบกำหนดเอง: ที่อยู่ IP ที่คุณกรอก คั่นด้วยเครื่องหมายจุลภาค
DNS over HTTPS: คำขอจะถูกเข้ารหัสและส่งไปยัง Cloudflare, Google, Quad9 หรือที่อยู่ https:// ที่คุณกรอก เครือข่ายของคุณจึงอ่านหรือแก้ไขคำขอไม่ได้

การบล็อกทำงานเหมือนกันทั้ง 3 แบบ หากต้องการใช้ DNS แบบเข้ารหัส ให้ใช้ DNS over HTTPS ที่นี่ แทนการตั้งค่า DNS ส่วนตัว ของ Android ซึ่งจะข้าม AdAway ไป

บล็อก อนุญาต หรือเปลี่ยนเส้นทางชื่อโฮสต์อย่างไร

จากหน้าแรก คุณจัดการรายการได้ 3 รายการ:

ถูกบล็อก: ชื่อโฮสต์ที่ควรถูกบล็อก (โฆษณาและตัวติดตาม)
อนุญาต: ข้อยกเว้นที่คุณไม่ต้องการให้ถูกบล็อกเลย แม้แหล่งที่มาจะระบุไว้ก็ตาม
เปลี่ยนเส้นทาง: ชื่อโฮสต์ที่คุณต้องการให้ชี้ไปยังที่อยู่ IP ที่กำหนด

คุณยังเปิดบันทึก DNSจากหน้าแรกเพื่อดูแบบเรียลไทม์ว่าแอปกำลังสอบถามชื่อโฮสต์ใดอยู่ แล้วบล็อกหรืออนุญาตจากตรงนั้นได้ทันที

ต้องรีสตาร์ท Android หลังเปลี่ยนรายการหรือไม่

ไม่ต้อง AdAway นำการเปลี่ยนแปลงไปใช้ทันที แต่แอปที่เปิดอยู่ก่อนแล้วอาจยังใช้การเชื่อมต่อเดิมและแคชของตัวเองต่อไป ให้ปิดแอปนั้นให้สนิท (บังคับหยุดในการตั้งค่า Android ของแอป) และล้างแคชหากยังมีโฆษณาแสดงอยู่ การรีสตาร์ท Android จำเป็นเพียงครั้งเดียวในโหมด root หลังเปิดใช้โมดูล systemless hosts ของ Magisk

ฉันใช้ตัวบล็อกโฆษณาในเบราว์เซอร์อยู่แล้ว ควรยกเว้นเบราว์เซอร์จาก AdAway หรือไม่

ไม่ ใช้ทั้งสองอย่างต่อไป AdAway บล็อกทั้งโดเมนสำหรับทุกแอป ตัวบล็อกในเบราว์เซอร์ เช่น uBlock Origin หรือตัวที่มีในตัวของ Vivaldi หรือ Brave ทำงานเฉพาะในเบราว์เซอร์ แต่ยังซ่อนบางส่วนของหน้าเว็บและบล็อกโฆษณาจากเว็บไซต์ที่ไม่สามารถบล็อกทั้งเว็บได้ การยกเว้นเบราว์เซอร์แทบไม่ได้อะไรเลย เพราะ AdAway ตรวจสอบชื่อได้แทบจะทันที และเบราว์เซอร์จะเสียการป้องกันของ AdAway ไป หากเบราว์เซอร์ใช้ DNS ที่ปลอดภัยของตัวเอง ให้ปิดไว้ (ดูแท็บปัญหา) ไม่เช่นนั้นจะข้าม AdAway ไป

หาแหล่งที่มา hosts เพิ่มเติมได้ที่ไหน

AdAway มาพร้อมค่าเริ่มต้นที่เหมาะสมอยู่แล้ว หากต้องการเพิ่ม ดูรายการแหล่งที่มา hosts เพิ่มเติมที่ชุมชนช่วยกันดูแล ควรเพิ่มแหล่งที่มาอย่างพอประมาณ เพราะรายการที่ใหญ่มากหรือซ้ำซ้อนกันอาจทำให้บล็อกผิดพลาดจนแอปใช้งานไม่ได้

ทำไมจึงมีฟอร์กนี้

AdAway เป็นโปรเจกต์ที่ยอดเยี่ยมและมีประวัติยาวนาน แต่ช่วงที่ผ่านมาต้นทางออกรุ่นใหม่และตรวจรับการแก้ไขได้ไม่บ่อยนัก การแก้ไขข้อบกพร่องและ pull request บางรายการค้างอยู่เป็นเวลานาน รวมถึงปัญหาที่กระทบความเสถียรของโหมด VPN บน Android เวอร์ชันใหม่ ๆ และ ROM ของผู้ผลิตโทรศัพท์ ฟอร์กนี้เกิดขึ้นเพื่อให้โปรเจกต์ยังใช้งานได้ต่อไปด้วยการแก้ไขที่ชุมชนช่วยกันดูแล แทนที่จะปล่อยให้การปรับปรุงที่ทดสอบแล้วไม่ได้ถูกนำไปใช้

แจ้งข้อบกพร่องหรือเสนอการเปลี่ยนแปลงได้อย่างไร
