AdAway Community ဆိုတာ ဘာလဲ။

AdAway Community သည် Android အတွက် ပွင့်လင်းရင်းမြစ် ကြော်ငြာပိတ်ဆို့စနစ် AdAway ကို အသိုင်းအဝိုင်းက ထိန်းသိမ်းထားသော၊ တရားဝင်မဟုတ်သည့် fork ဖြစ်ပါသည်။ ၎င်းသည် အကောင့်မလိုဘဲ၊ ကိုယ်ပိုင်ကြော်ငြာလည်း မပါဘဲ အက်ပ်အားလုံးအတွက် စနစ်တစ်ခုလုံးတွင် ကြော်ငြာများနှင့် ခြေရာခံကိရိယာများကို ပိတ်ဆို့ပေးပါသည်။ ဤ fork သည် ခေတ်သစ် Android ဗားရှင်းများနှင့် ထုတ်လုပ်သူ ROM များတွင် အက်ပ်ကို ယုံကြည်စိတ်ချစွာ ဆက်လက်အလုပ်လုပ်စေရေးကို အဓိကထားပါသည်။

ကြော်ငြာများကို မည်သို့ ပိတ်ဆို့သနည်း။

AdAway သည် မုဒ်နှစ်မျိုးထဲက တစ်မျိုးဖြင့် အလုပ်လုပ်ပါသည်။

VPN မုဒ် (root မလိုပါ): AdAway သည် သင့်အသွားအလာကို ဘယ်နေရာသို့မျှ မပို့သော စက်တွင်း VPN တစ်ခုကို လည်ပတ်စေပါသည်။ ၎င်းသည် DNS တောင်းဆိုမှုများကိုသာ စစ်ဆေးပြီး ကြော်ငြာနှင့် ခြေရာခံ hostname များသို့ ညွှန်သည့်အရာများကို ပယ်ချကာ ကျန်အရာအားလုံးကို ဖြတ်သန်းခွင့်ပေးပါသည်။ သင့်စက်မှ ဘာမျှ အပြင်သို့ မထွက်ပါ။

root မုဒ်: သင့်စက်ကို root လုပ်ထားပါက AdAway သည် အစားထိုး၍ hosts ဖိုင် တစ်ခုကို /system/etc/hosts သို့ ရေးနိုင်ပြီး မလိုချင်သော hostname များကို 127.0.0.1 သို့ ချိတ်ဆက်ကာ သင့်စက်ကိုယ်တိုင်သို့ ဖြေရှင်းစေပါသည်။ Android ဗားရှင်းအသစ်များတွင် systemless hosts မော်ဂျူး (ဥပမာ Magisk) လိုအပ်ပါသည်။

VPN သည် မည်သည့် DNS ဆာဗာများကို အသုံးပြုသနည်း။

VPN မုဒ်တွင် ပိတ်ဆို့မထားသော hostname များကို စိတ်ကြိုက်ဆက်တင်များ › VPN အခြေပြု ကြော်ငြာပိတ်ဆို့စနစ် › DNS ဆာဗာများ တွင် သင်ရွေးထားသော DNS ဆာဗာများက ဖြေရှင်းပေးပါသည်။

ကွန်ရက်၏ DNS ဆာဗာများ (မူလ): သင့် Wi-Fi သို့မဟုတ် မိုဘိုင်းကွန်ရက်၏ ဆာဗာများ။ AdAway အသုံးပြုနိုင်သည့် ဆာဗာကို ကွန်ရက်က မပေးပါက Cloudflare (1.1.1.1) သို့ ပြောင်းသုံးပါသည်။
စိတ်ကြိုက် DNS ဆာဗာများ: သင်ထည့်သော IP လိပ်စာများ၊ ကော်မာဖြင့် ခြားထားသည်။
DNS over HTTPS: တောင်းဆိုမှုများကို ကုဒ်ဝှက်ပြီး Cloudflare၊ Google၊ Quad9 သို့မဟုတ် သင်ထည့်သော https:// လိပ်စာသို့ ပို့ပါသည်။ ထို့ကြောင့် သင့်ကွန်ရက်က ၎င်းတို့ကို မဖတ်နိုင်ဘဲ မပြောင်းလဲနိုင်ပါ။

ပိတ်ဆို့မှုသည် သုံးမျိုးလုံးတွင် အတူတူပင် အလုပ်လုပ်ပါသည်။ ကုဒ်ဝှက်ထားသော DNS ကို ဆက်ထားလိုပါက AdAway ကို ကျော်လွှားသည့် Android ၏ ပုဂ္ဂလိက DNS ဆက်တင်အစား ဤနေရာရှိ DNS over HTTPS ကို သုံးပါ။

hostname တစ်ခုကို ပိတ်ဆို့ရန်၊ ခွင့်ပြုရန် သို့မဟုတ် ပြန်လွှဲရန် မည်သို့ လုပ်ရမည်နည်း။

ပင်မစခရင်မှ စာရင်းသုံးခုကို စီမံနိုင်ပါသည်။

ပိတ်ဆို့ထားသည်: ပိတ်ဆို့သင့်သော hostname များ (ကြော်ငြာများနှင့် ခြေရာခံကိရိယာများ)။
ခွင့်ပြုထားသည်: ရင်းမြစ်က စာရင်းသွင်းထားလျှင်ပင် မည်သည့်အခါမျှ မပိတ်ဆို့စေလိုသော ခြွင်းချက်များ။
ပြန်လွှဲထားသည်: သီးခြား IP လိပ်စာတစ်ခုသို့ ညွှန်စေလိုသော hostname များ။

ပင်မစခရင်မှ DNS မှတ်တမ်း ကိုလည်း ဖွင့်၍ အက်ပ်များက မည်သည့် hostname များကို အချိန်နှင့်တစ်ပြေးညီ မေးမြန်းနေသည်ကို ကြည့်နိုင်ပြီး ထိုနေရာမှပင် တိုက်ရိုက် ပိတ်ဆို့နိုင်သည် သို့မဟုတ် ခွင့်ပြုနိုင်ပါသည်။

စာရင်းများကို ပြောင်းပြီးနောက် Android ကို ပြန်စတင်ရန် လိုပါသလား။

မလိုပါ။ AdAway သည် ပြောင်းလဲမှုကို ချက်ချင်း အသုံးပြုသော်လည်း ဖွင့်ထားပြီးသား အက်ပ်သည် ၎င်း၏ ယခင်ချိတ်ဆက်မှုများနှင့် ကိုယ်ပိုင်ကက်ရှ်ကို ဆက်သုံးနေနိုင်ပါသည်။ ၎င်းကို လုံးဝပိတ်ပါ (အက်ပ်၏ Android ဆက်တင်တွင် အတင်းရပ်ရန်)၊ ကြော်ငြာများ ဆက်ပေါ်နေပါက ၎င်း၏ ကက်ရှ်ကိုလည်း ရှင်းလင်းပါ။ Android ကို ပြန်စတင်ရန် လိုအပ်သည်မှာ root မုဒ်တွင် Magisk systemless hosts မော်ဂျူးကို ဖွင့်ပြီးနောက် တစ်ကြိမ်သာ ဖြစ်သည်။

hosts ရင်းမြစ် ထပ်မံရှာရန် မည်သည့်နေရာတွင် ရနိုင်သနည်း။

AdAway တွင် သင့်တော်သော မူလသတ်မှတ်ချက်များ ပါဝင်ပါသည်။ ပိုလိုချင်ပါက အသိုင်းအဝိုင်းက ထိန်းသိမ်းထားသော ထပ်ဆောင်း hosts ရင်းမြစ်များ စာရင်း ကို ကြည့်ပါ။ ရင်းမြစ်များကို သင့်တင့်သလောက်သာ ထပ်ထည့်ပါ၊ အလွန်ကြီးသော သို့မဟုတ် အချင်းချင်း ထပ်နေသော စာရင်းများသည် အက်ပ်များကို ပျက်စေသည့် မှားယွင်းသော ပိတ်ဆို့မှုများ ဖြစ်စေနိုင်သောကြောင့် ဖြစ်သည်။

ဤ fork ကို အဘယ်ကြောင့် ပြုလုပ်ထားသနည်း။

AdAway သည် သမိုင်းကြောင်းရှည်လျားသော ကောင်းမွန်သည့် ပရောဂျက်တစ်ခု ဖြစ်သော်လည်း မူလပရောဂျက်၏ ထုတ်ဝေမှုနှင့် ပြန်လည်သုံးသပ်မှု လှုပ်ရှားမှုများမှာ ကာလအတော်ကြာ အကန့်အသတ်ရှိခဲ့ပါသည်။ ခေတ်သစ် Android ဗားရှင်းများနှင့် ထုတ်လုပ်သူ ROM များတွင် VPN မုဒ်၏ တည်ငြိမ်မှုကို ထိခိုက်သည့် ပြဿနာများအပါအဝင် ချို့ယွင်းချက်ပြင်ဆင်မှုများနှင့် pull request အချို့သည် အချိန်ကြာမြင့်စွာ ဖွင့်လျက် ကျန်ခဲ့ပါသည်။ စမ်းသပ်ပြီးသော တိုးတက်မှုများကို အသုံးမပြုဘဲ ထားရှိမည့်အစား အသိုင်းအဝိုင်းက ထိန်းသိမ်းသော ပြင်ဆင်ချက်များဖြင့် ပရောဂျက်ကို ဆက်လက်အသုံးပြုနိုင်စေရန် ဤ fork ကို ပြုလုပ်ထားခြင်း ဖြစ်ပါသည်။

ချို့ယွင်းချက်ကို မည်သို့ တင်ပြရမည်နည်း၊ ပြောင်းလဲမှုကို မည်သို့ အကြံပြုရမည်နည်း။
