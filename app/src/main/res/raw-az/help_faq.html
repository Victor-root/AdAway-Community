AdAway Community nədir?

AdAway Community, Android üçün açıq mənbəli reklam bloklayıcı olan AdAway layihəsinin qeyri-rəsmi, icma tərəfindən dəstəklənən forkudur. Reklamları və izləyiciləri bütün tətbiqlər üçün sistem miqyasında bloklayır, hesab tələb etmir və özündə reklam yoxdur. Bu fork tətbiqin Android-in müasir versiyalarında və istehsalçı ROM-larında etibarlı işləməsini təmin etməyə yönəlib.

Reklamları necə bloklayır?

AdAway iki rejimdən birində işləyir:

VPN rejimi (root tələb olunmur): AdAway cihazda yerli VPN işə salır və bu VPN trafikinizi heç yerə göndərmir. O, yalnız DNS sorğularına baxır, reklam və izləyici host adlarına gedənləri dayandırır, qalanlarını isə buraxır. Heç nə cihazınızdan kənara çıxmır.

Root rejimi: cihazınızda root varsa, AdAway əvəzində hosts faylını /system/etc/hosts ünvanına yaza bilər. Bu fayl arzuolunmaz host adlarını 127.0.0.1 ünvanına yönləndirir, beləliklə onlar sizin öz cihazınıza həll olunur. Android-in son versiyalarında systemless hosts modulu (məsələn, Magisk) tələb olunur.

VPN hansı DNS serverlərindən istifadə edir?

VPN rejimində bloklanmayan host adları Tənzimləmələr › VPN əsaslı reklam bloklayıcı › DNS serverləri bölməsində seçdiyiniz DNS serverləri ilə həll olunur:

Şəbəkənin DNS serverləri (defolt): Wi-Fi və ya mobil şəbəkənizin serverləri. Şəbəkə AdAway-in istifadə edə biləcəyi server təqdim etmirsə, Cloudflare (1.1.1.1) istifadə olunur.
Fərdi DNS serverləri: vergüllə ayıraraq daxil etdiyiniz IP ünvanları.
DNS over HTTPS: sorğular şifrələnir və Cloudflare, Google, Quad9 və ya daxil etdiyiniz https:// ünvanına göndərilir, beləliklə şəbəkəniz onları oxuya və ya dəyişdirə bilmir.

Bloklama hər üç halda eyni şəkildə işləyir. Şifrələnmiş DNS saxlamaq üçün burada Android-in AdAway tətbiqini yan keçən Şəxsi DNS ayarı əvəzinə DNS over HTTPS seçin.

Host adını necə bloklayım, ona necə icazə verim və ya onu necə yönləndirim?

Ana ekrandan üç siyahını idarə edirsiniz:

Bloklananlar: bloklanmalı olan host adları (reklamlar və izləyicilər).
İcazə verilənlər: mənbə onları siyahıya salsa belə, heç vaxt bloklanmasını istəmədiyiniz istisnalar.
Yönləndirilənlər: konkret IP ünvanına yönləndirmək istədiyiniz host adları.

Tətbiqlərin real vaxtda hansı host adlarını sorğuladığını görmək üçün ana ekrandan DNS jurnalı bölməsini də aça bilərsiniz, sonra onları birbaşa oradan bloklaya və ya onlara icazə verə bilərsiniz.

Siyahılarımı dəyişdikdən sonra Android-i yenidən başlatmaq lazımdırmı?

Xeyr. AdAway dəyişikliyi dərhal tətbiq edir, lakin artıq açıq olan tətbiq köhnə bağlantılarından və öz keşindən istifadəyə davam edə bilər. Onu tamamilə bağlayın (tətbiqin Android ayarlarında Məcburi dayandır), reklamlar hələ də görünürsə, keşini təmizləyin. Android-i yenidən başlatmaq yalnız root rejimində, Magisk-in systemless hosts modulunu aktiv etdikdən sonra bir dəfə lazım olur.

Daha çox hosts mənbəsini haradan tapa bilərəm?

AdAway ağlabatan defolt mənbələrlə gəlir. Daha çox istəyirsinizsə, icma tərəfindən saxlanılan əlavə hosts mənbələri siyahısına baxın. Mənbələri az-az əlavə edin, çünki çox böyük və ya bir-birini təkrarlayan siyahılar tətbiqləri korlayan yalan nəticələrə səbəb ola bilər.

Bu fork niyə mövcuddur?

AdAway uzun tarixə malik əla layihədir, lakin əsas layihədə buraxılış və nəzərdən keçirmə fəaliyyəti bir müddətdir məhduddur. Bəzi düzəlişlər və dəyişiklik təklifləri uzun müddət açıq qalıb, o cümlədən Android-in son versiyalarında və istehsalçı ROM-larında VPN rejiminin sabitliyinə təsir edən problemlər. Bu fork layihənin istifadə oluna bilən qalması üçün, sınaqdan keçmiş təkmilləşdirmələrin istifadəsiz qalması əvəzinə icmanın saxladığı düzəlişlərlə mövcuddur.

Xətanı necə bildirim və ya dəyişiklik necə təklif edim?

Forkun izləyicisində məsələ açın: https://github.com/Victor-root/AdAway-Community/issues. VPN problemlərini bildirərkən diaqnostika jurnalı (Problemlər bölməsinə baxın) çox kömək edir.
