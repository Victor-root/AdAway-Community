AdAway Community 是什么？

AdAway Community 是 AdAway（Android 上的开源广告拦截器）的非官方社区维护复刻版。它能在全系统范围内拦截广告和跟踪器，对所有应用生效，无需账号，自身也没有任何广告。这个复刻版的重点，是让应用在新版 Android 和各厂商定制系统上保持稳定可靠。

它是如何拦截广告的？

AdAway 有两种工作模式：

VPN 模式（无需 root）：AdAway 在设备上运行一个本地 VPN，绝不会把您的流量发送到别处。它只检查 DNS 请求，丢弃指向广告和跟踪器主机名的请求，其余一律放行。没有任何内容会离开您的设备。

root 模式：如果您的设备已 root，AdAway 也可以改为将 hosts 文件写入 /system/etc/hosts，把不想要的主机名映射到 127.0.0.1，使它们解析到您自己的设备上。在较新的 Android 上，需要使用 systemless hosts 模块（例如 Magisk）。

VPN 使用哪些 DNS 服务器？

在 VPN 模式下，未被拦截的主机名会由您在设置 › 基于 VPN 的广告拦截 › DNS 服务器中选择的 DNS 服务器来解析：

网络 DNS 服务器（默认）：您的 Wi-Fi 或移动网络提供的服务器。如果网络没有提供 AdAway 可用的服务器，则回退到 Cloudflare（1.1.1.1）。
自定义 DNS 服务器：您输入的 IP 地址，以英文逗号分隔。
DNS over HTTPS：请求会被加密并发送到 Cloudflare、Google、Quad9 或您输入的 https:// 地址，因此您的网络无法读取或篡改它们。

这三种方式的拦截效果相同。如果想使用加密 DNS，请在这里选择 DNS over HTTPS，而不要使用 Android 的私人 DNS设置，因为后者会绕过 AdAway。

如何拦截、允许或重定向某个主机名？

在主屏幕上，您可以管理三个列表：

已拦截：需要被拦截的主机名（广告和跟踪器）。
已允许：您希望永不拦截的例外项，即使某个来源将其列入也不例外。
已重定向：您希望指向某个特定 IP 地址的主机名。

您还可以在主屏幕打开DNS 日志，实时查看各个应用正在查询哪些主机名，并直接在那里拦截或允许它们。

更改列表后需要重启 Android 吗？

不需要。AdAway 会立即应用更改，但已经打开的应用可能仍会沿用旧的连接和自己的缓存。请彻底关闭该应用（在 Android 设置的应用信息中选择强行停止），如果仍有广告显示，再清除它的缓存。只有在 root 模式下，启用 Magisk 的 systemless hosts 模块后，才需要重启一次 Android。

我已在浏览器中使用广告拦截器：需要将浏览器排除在 AdAway 之外吗？

不需要，两者都保留。AdAway 为所有应用拦截整个域名。浏览器拦截器（例如 uBlock Origin，或 Vivaldi、Brave 内置的拦截器）只在浏览器中起作用，但它还能隐藏页面中的元素，并拦截那些无法整体拦截的网站所投放的广告。排除浏览器几乎没有任何好处，因为 AdAway 检查一个域名几乎是瞬间完成的，而浏览器却会失去 AdAway 的保护。如果浏览器使用自己的安全 DNS，请将其关闭（参见“问题排查”标签页），否则它会绕过 AdAway。

在哪里可以找到更多 hosts 来源？

AdAway 自带了合理的默认设置。如果您想要更多，请参阅社区维护的附加 hosts 来源列表。请适度添加来源，因为过大或相互重叠的列表可能造成误拦截，导致应用无法正常使用。

为什么会有这个复刻版？

AdAway 是一个很棒的、历史悠久的项目，但上游的发布和审阅活动已经有一段时间比较少了。一些错误修复和合并请求长期处于未处理状态，其中包括影响新版 Android 和各厂商定制系统上 VPN 模式稳定性的问题。这个复刻版的存在，是为了借助社区维护的修复让项目保持可用，而不是任由经过测试的改进闲置。

如何报告错误或提出修改建议？

请在这个复刻版的问题跟踪页面提交问题：https://github.com/Victor-root/AdAway-Community/issues。报告 VPN 相关问题时，附上诊断日志（见“问题排查”标签页）会很有帮助。
