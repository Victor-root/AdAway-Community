Le RPV/VPN se coupe tout seul

C'est presque toujours le système qui coupe le service RPV/VPN pour économiser la batterie, pas un plantage. C'est fréquent sur les ROM constructeurs à gestion d'énergie agressive (ColorOS/Oppo, MIUI/Xiaomi, EMUI/Huawei, OneUI/Samsung, etc.).

Dans les paramètres Android, trouvez AdAway et : réglez l'optimisation de la batterie sur Sans restriction (ou Ne pas optimiser), autorisez le démarrage automatique si votre ROM le propose, et verrouillez AdAway dans la liste des applications récentes pour ne pas le balayer. Vérifiez aussi que Activer au démarrage est coché dans les préférences RPV/VPN d'AdAway.

Pas d'internet ou navigation lente juste après un passage Wi-Fi ↔ données mobiles

Quand le réseau actif change, le tunnel doit être reconstruit pour que le DNS soit résolu depuis le nouveau réseau. Si la navigation reste cassée, ouvrez Préférences › VPN › Réinitialiser le RPV/VPN pour reconstruire la connexion. Si cela se reproduit, capturez un journal de diagnostic (ci-dessous) et signalez-le.

Comment exporter un journal de diagnostic ?

Ouvrez Préférences › VPN › Journal de diagnostic. Il enregistre les erreurs et événements RPV/VPN récents (changements de réseau, reconnexions, échecs), pas votre historique de navigation, seulement des événements techniques. Utilisez Copier ou Partager pour l'envoyer lors d'un signalement. Astuce : Effacez-le d'abord, puis reproduisez le problème, pour un journal ciblé.

Chrome affiche encore des publicités

Chrome peut utiliser son propre DNS sécurisé (DNS-over-HTTPS), qui contourne AdAway. Dans Chrome, ouvrez Paramètres › Confidentialité et sécurité › Utiliser un DNS sécurisé et désactivez-le. Cela vaut aussi pour tout paramètre DNS privé d'une application ou du système.

Certaines publicités passent encore, ou une application en affiche

Un domaine peut manquer dans vos sources, ou l'application intègre ses publicités sans faire de requête. Ouvrez le journal DNS depuis l'accueil pour voir ce que l'application interroge, ajoutez les domaines suspects à votre liste Bloqués, et vérifiez que rien ne casse. Certaines applications gardent aussi les publicités en cache après les avoir téléchargées, donc vider le cache de l'application dans les paramètres Android peut aider.

Une application ne fonctionne plus après l'activation d'AdAway

Certaines applications refusent de fonctionner quand un domaine dont elles ont besoin est bloqué. Utilisez le journal DNS pour trouver ce domaine, ajoutez-le à votre liste Autorisés, et l'application devrait refonctionner. Les applications problématiques connues sont listées ici.

L'application du fichier hosts échoue (mode root)

Les versions récentes d'Android utilisent une partition /system en lecture seule, donc AdAway ne peut pas y écrire directement. Si vous utilisez Magisk, activez le module systemless hosts, redémarrez, puis réappliquez. Sans root, utilisez plutôt le mode RPV/VPN, qui ne modifie pas le système.

Toujours bloqué ?

Signalez le problème avec un journal de diagnostic joint sur https://github.com/Victor-root/AdAway-Community/issues.
