Qu'est-ce qu'AdAway Community ?

AdAway Community est un fork non officiel, maintenu par la communauté, d'AdAway, le bloqueur de publicités open source pour Android. Il bloque les publicités et les traqueurs pour toutes les applications, sans compte et sans publicité. Ce fork vise à garder l'application fiable sur les versions récentes d'Android et les ROM constructeurs.

Comment ça bloque les publicités ?

AdAway fonctionne selon deux modes :

Mode RPV/VPN (par défaut, sans root) : AdAway lance un RPV/VPN local, sur l'appareil, qui n'envoie votre trafic nulle part. Il inspecte seulement les requêtes DNS et écarte celles qui pointent vers des domaines de publicité ou de pistage, en laissant passer tout le reste. Rien ne quitte votre appareil.

Mode root : si votre appareil est rooté, AdAway peut écrire un fichier hosts dans /system/etc/hosts, qui redirige les domaines indésirables vers 127.0.0.1 (votre propre appareil). Sur Android récent, un module hosts « systemless » (ex. Magisk) est nécessaire.

Comment bloquer, autoriser ou rediriger un domaine ?

Depuis l'écran d'accueil, vous gérez trois listes :

Bloqués : les domaines à bloquer (publicités et traqueurs).
Autorisés : les exceptions à ne jamais bloquer, même si une source les contient.
Redirigés : les domaines à pointer vers une adresse IP précise.

Vous pouvez aussi ouvrir le journal DNS depuis l'accueil pour voir en temps réel les domaines interrogés par les applications, puis les bloquer ou les autoriser directement.

Où trouver d'autres sources de hosts ?

AdAway est fourni avec des sources par défaut raisonnables. Pour aller plus loin, consultez la liste de sources hosts supplémentaires maintenue par la communauté. Ajoutez des sources avec parcimonie, car des listes très volumineuses ou redondantes peuvent provoquer des faux positifs qui cassent des applications.

Pourquoi ce fork existe ?

AdAway est un excellent projet avec une longue histoire, mais l'activité de publication et de revue en amont est limitée depuis un moment. Des corrections et des demandes de fusion sont restées ouvertes longtemps, notamment des problèmes de stabilité du mode RPV/VPN sur les versions récentes d'Android et les ROM constructeurs. Ce fork existe pour garder le projet utilisable avec des correctifs communautaires, au lieu de laisser des améliorations testées inutilisées.

Comment signaler un bug ou proposer un changement ?

Ouvrez un ticket sur le dépôt du fork : https://github.com/Victor-root/AdAway-Community/issues. Un journal de diagnostic (voir l'onglet Problèmes) aide beaucoup pour les problèmes de RPV/VPN.
