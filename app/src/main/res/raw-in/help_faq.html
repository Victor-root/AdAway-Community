Apa itu AdAway Community?

AdAway Community adalah fork tidak resmi dari AdAway yang dikelola komunitas, pemblokir iklan open source untuk Android. Aplikasi ini memblokir iklan dan pelacak di seluruh sistem, untuk semua aplikasi, tanpa akun dan tanpa iklan sendiri. Fork ini berfokus menjaga aplikasi tetap berfungsi andal di Android versi terbaru dan ROM bawaan produsen.

Bagaimana cara AdAway memblokir iklan?

AdAway bekerja dalam salah satu dari dua mode:

Mode VPN (tanpa root): AdAway menjalankan VPN lokal di perangkat yang tidak pernah mengirim lalu lintas Anda ke mana pun. VPN ini hanya memeriksa permintaan DNS dan membuang permintaan yang mengarah ke nama host iklan dan pelacak, sementara yang lain dibiarkan lewat. Tidak ada yang keluar dari perangkat Anda.

Mode root: jika perangkat Anda sudah di-root, AdAway dapat menulis file hosts ke /system/etc/hosts, yang memetakan nama host yang tidak diinginkan ke 127.0.0.1 sehingga mengarah ke perangkat Anda sendiri. Pada Android terbaru, diperlukan modul hosts tanpa modifikasi sistem (systemless), misalnya Magisk.

Server DNS mana yang digunakan VPN?

Dalam mode VPN, nama host yang tidak diblokir diselesaikan oleh server DNS yang Anda pilih di Preferensi › Pemblokir iklan berbasis VPN › Server DNS:

Server DNS jaringan (default): server milik jaringan Wi-Fi atau seluler Anda. Jika jaringan tidak menyediakan server yang dapat digunakan AdAway, AdAway beralih ke Cloudflare (1.1.1.1).
Server DNS khusus: alamat IP yang Anda masukkan, dipisahkan dengan koma.
DNS over HTTPS: permintaan dienkripsi dan dikirim ke Cloudflare, Google, Quad9, atau alamat https:// yang Anda masukkan, sehingga jaringan Anda tidak dapat membaca atau mengubahnya.

Pemblokiran bekerja sama pada ketiganya. Untuk tetap menggunakan DNS terenkripsi, gunakan DNS over HTTPS di sini, bukan setelan DNS Pribadi milik Android, karena setelan itu melewati AdAway.

Bagaimana cara memblokir, mengizinkan, atau mengalihkan nama host?

Dari layar utama, Anda mengelola tiga daftar:

Diblokir: nama host yang harus diblokir (iklan dan pelacak).
Diizinkan: pengecualian yang tidak ingin Anda blokir, meskipun tercantum di sebuah sumber.
Dialihkan: nama host yang ingin Anda arahkan ke alamat IP tertentu.

Anda juga dapat membuka Log DNS dari layar utama untuk melihat nama host apa saja yang diminta aplikasi secara real-time, lalu memblokir atau mengizinkannya langsung dari sana.

Apakah saya perlu memulai ulang Android setelah mengubah daftar?

Tidak. AdAway menerapkan perubahan seketika, tetapi aplikasi yang sudah terbuka dapat terus memakai koneksi lamanya dan cache-nya sendiri. Tutup aplikasi tersebut sepenuhnya (Paksa berhenti di setelan Android untuk aplikasi itu), dan hapus cache-nya jika iklan masih muncul. Mulai ulang Android hanya diperlukan satu kali pada mode root, setelah mengaktifkan modul systemless hosts dari Magisk.

Di mana saya dapat menemukan sumber hosts lainnya?

AdAway sudah menyertakan pengaturan default yang masuk akal. Jika Anda menginginkan lebih banyak, lihat daftar sumber hosts tambahan yang dikelola komunitas. Tambahkan sumber seperlunya saja, karena daftar yang sangat besar atau saling tumpang tindih dapat menyebabkan salah blokir yang merusak aplikasi.

Mengapa fork ini ada?

AdAway adalah proyek hebat dengan sejarah panjang, tetapi aktivitas rilis dan peninjauan di upstream sudah cukup lama terbatas. Beberapa perbaikan bug dan pull request tetap terbuka dalam waktu lama, termasuk masalah yang memengaruhi stabilitas mode VPN pada Android versi terbaru dan ROM bawaan produsen. Fork ini ada untuk menjaga proyek tetap dapat digunakan melalui perbaikan yang dikelola komunitas, agar peningkatan yang sudah diuji tidak terbengkalai.

Bagaimana cara melaporkan bug atau mengusulkan perubahan?

Buka isu di pelacak milik fork ini: https://github.com/Victor-root/AdAway-Community/issues. Log diagnostik (lihat tab Masalah) sangat membantu saat melaporkan masalah VPN.
