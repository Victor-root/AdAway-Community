What is AdAway Community?

AdAway Community is an unofficial, community-maintained fork of AdAway, the open-source ad blocker for Android. It blocks ads and trackers system-wide, for every app, with no account and no ads of its own. This fork focuses on keeping the app working reliably on modern Android versions and OEM ROMs.

How does it block ads?

AdAway works in one of two modes:

VPN mode (default, no root needed): AdAway runs a local, on-device VPN that never sends your traffic anywhere. It only inspects DNS requests and drops the ones pointing to ad and tracker hostnames, letting everything else through. Nothing leaves your device.

Root mode: if your device is rooted, AdAway can instead write a hosts file to /system/etc/hosts, mapping unwanted hostnames to 127.0.0.1 so they resolve to your own device. On recent Android, a systemless hosts module (e.g. Magisk) is required.

How do I block, allow or redirect a hostname?

From the home screen you manage three lists:

Blocked: hostnames that should be blocked (ads and trackers).
Allowed: exceptions you never want blocked, even if a source lists them.
Redirected: hostnames you want pointed to a specific IP address.

You can also open the DNS log from the home screen to see which hostnames apps are querying in real time, then block or allow them directly from there.

Where can I find more hosts sources?

AdAway ships with sensible defaults. If you want more, see the community-maintained list of additional hosts sources. Add more sources sparingly, because very large or overlapping lists can cause false positives that break apps.

Why does this fork exist?

AdAway is a great project with a long history, but upstream release and review activity has been limited for a while. Some bug fixes and pull requests stayed open for a long time, including issues affecting VPN-mode stability on recent Android versions and OEM ROMs. This fork exists to keep the project usable with community-maintained fixes instead of letting tested improvements sit unused.

How do I report a bug or suggest a change?

Open an issue on the fork's tracker: https://github.com/Victor-root/AdAway-Community/issues. A diagnostic log (see the Problems tab) helps a lot when reporting VPN issues.
