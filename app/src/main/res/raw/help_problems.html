The VPN turns off by itself

This is almost always the system killing the VPN service to save battery, not a crash. It is common on OEM ROMs with aggressive power management (ColorOS/Oppo, MIUI/Xiaomi, EMUI/Huawei, OneUI/Samsung, and others).

In Android settings, find AdAway and: set battery optimization to Unrestricted (or Don't optimize), allow autostart/auto-launch if your ROM has it, and lock AdAway in the recent-apps list so it is not swiped away. Also make sure Enable at startup is on in AdAway's VPN preferences.

No internet or slow browsing right after switching between Wi-Fi and mobile

When the active network changes, the tunnel has to be rebuilt so DNS is resolved from the new network. If browsing stays broken, open Preferences, VPN, Reset VPN to rebuild the connection from scratch. If it keeps happening, capture a diagnostic log (below) and report it.

How do I export a diagnostic log?

Open Preferences, VPN, Diagnostic log. It records recent errors and VPN events (network switches, reconnections, failures), not your browsing history, just technical events. Use Copy or Share to send it when reporting a problem. Tip: Clear it first, then reproduce the issue, so the log is focused.

Chrome still shows ads

Chrome can use its own Secure DNS (DNS-over-HTTPS), which bypasses AdAway. In Chrome, open Settings, Privacy and security, Use secure DNS and turn it off. The same applies to any app or system Private DNS setting.

Some ads still get through, or an app still shows ads

A hostname may be missing from your sources, or the app bundles its ads so no request is made. Open the DNS log from the home screen to see what the app is querying, add the suspicious hostnames to your Blocked list, and verify nothing breaks. Some apps also cache ads after downloading them, so clearing that app's cache in Android settings can help.

An app stopped working after enabling AdAway

Some apps refuse to work when a hostname they need is blocked. Use the DNS log to find which hostname the app needs, add it to your Allowed list, and the app should work again. Known problematic apps are listed here.

Applying the hosts file fails (root mode)

Recent Android versions use a read-only /system partition, so AdAway cannot write there directly. If you use Magisk, enable the systemless hosts module, reboot, and apply again. If you do not use root, switch to VPN mode instead, which needs no system modification.
