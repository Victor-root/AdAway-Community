តើ AdAway Community ជាអ្វី?

AdAway Community គឺជា fork មិនផ្លូវការរបស់ AdAway ដែលថែទាំដោយសហគមន៍ ជាកម្មវិធីទប់ស្កាត់ពាណិជ្ជកម្មប្រភពបើកចំហសម្រាប់ Android។ វាទប់ស្កាត់ពាណិជ្ជកម្ម និងកម្មវិធីតាមដានទូទាំងប្រព័ន្ធ សម្រាប់គ្រប់កម្មវិធី ដោយមិនត្រូវការគណនី ហើយក៏គ្មានពាណិជ្ជកម្មផ្ទាល់ខ្លួនដែរ។ fork នេះផ្តោតលើការរក្សាឱ្យកម្មវិធីដំណើរការបានដោយភាពជឿជាក់នៅលើកំណែ Android ថ្មីៗ និង ROM របស់ក្រុមហ៊ុនផលិត។

តើវាទប់ស្កាត់ពាណិជ្ជកម្មដោយរបៀបណា?

AdAway ដំណើរការតាមរបៀបមួយក្នុងចំណោមពីរ:

របៀប VPN (មិនត្រូវការ root): AdAway ដំណើរការ VPN ក្នុងឧបករណ៍ ដែលមិនដែលបញ្ជូនចរាចរណ៍របស់អ្នកទៅកន្លែងណាឡើយ។ វាពិនិត្យតែសំណើ DNS ហើយទម្លាក់សំណើណាដែលចង្អុលទៅឈ្មោះ host របស់ពាណិជ្ជកម្ម និងកម្មវិធីតាមដាន ដោយទុកឱ្យអ្វីៗផ្សេងទៀតឆ្លងកាត់។ គ្មានអ្វីចេញពីឧបករណ៍របស់អ្នកឡើយ។

របៀប root: ប្រសិនបើឧបករណ៍របស់អ្នកបាន root AdAway អាចសរសេរ ឯកសារ hosts ទៅ /system/etc/hosts ជំនួសវិញ ដោយភ្ជាប់ឈ្មោះ host ដែលមិនចង់បានទៅ 127.0.0.1 ដើម្បីឱ្យវាត្រូវបានដោះស្រាយទៅឧបករណ៍របស់អ្នកផ្ទាល់។ នៅលើ Android ថ្មីៗ ត្រូវការម៉ូឌុល systemless hosts (ឧទាហរណ៍ Magisk)។

តើ VPN ប្រើម៉ាស៊ីនមេ DNS ណាខ្លះ?

នៅក្នុងរបៀប VPN ឈ្មោះ host ដែលមិនត្រូវបានទប់ស្កាត់ ត្រូវបានដោះស្រាយដោយម៉ាស៊ីនមេ DNS ដែលអ្នកជ្រើសរើសនៅក្នុង ការកំណត់ › កម្មវិធីទប់ស្កាត់ពាណិជ្ជកម្មតាម VPN › ម៉ាស៊ីនមេ DNS:

ម៉ាស៊ីនមេ DNS របស់បណ្តាញ (លំនាំដើម): ម៉ាស៊ីនមេរបស់បណ្តាញ Wi-Fi ឬបណ្តាញទូរសព្ទចល័តរបស់អ្នក។ ប្រសិនបើបណ្តាញមិនផ្តល់ម៉ាស៊ីនមេដែល AdAway អាចប្រើបាន វានឹងប្តូរទៅប្រើ Cloudflare (1.1.1.1)។
ម៉ាស៊ីនមេ DNS ផ្ទាល់ខ្លួន: អាសយដ្ឋាន IP ដែលអ្នកបញ្ចូល បំបែកដោយសញ្ញាក្បៀស។
DNS over HTTPS: សំណើត្រូវបានអ៊ិនគ្រីប ហើយផ្ញើទៅ Cloudflare, Google, Quad9 ឬអាសយដ្ឋាន https:// ដែលអ្នកបញ្ចូល ដូច្នេះបណ្តាញរបស់អ្នកមិនអាចអាន ឬកែប្រែវាបានទេ។

ការទប់ស្កាត់ដំណើរការដូចគ្នាជាមួយទាំងបី។ ដើម្បីរក្សា DNS ដែលបានអ៊ិនគ្រីប សូមប្រើ DNS over HTTPS នៅទីនេះ ជាជាងការកំណត់ DNS ឯកជន របស់ Android ដែលចៀសផុតពី AdAway។

តើទប់ស្កាត់ អនុញ្ញាត ឬបញ្ជូនឈ្មោះ host បន្តដោយរបៀបណា?

ពីអេក្រង់ដើម អ្នកគ្រប់គ្រងបញ្ជីបី:

បានទប់ស្កាត់: ឈ្មោះ host ដែលត្រូវទប់ស្កាត់ (ពាណិជ្ជកម្ម និងកម្មវិធីតាមដាន)។
បានអនុញ្ញាត: ករណីលើកលែងដែលអ្នកមិនចង់ឱ្យត្រូវបានទប់ស្កាត់ឡើយ ទោះប្រភពណាមួយរាយវាក៏ដោយ។
បានបញ្ជូនបន្ត: ឈ្មោះ host ដែលអ្នកចង់ឱ្យចង្អុលទៅអាសយដ្ឋាន IP ជាក់លាក់មួយ។

អ្នកក៏អាចបើក កំណត់ហេតុ DNS ពីអេក្រង់ដើម ដើម្បីមើលថាកម្មវិធីកំពុងស្នើឈ្មោះ host ណាខ្លះភ្លាមៗ រួចទប់ស្កាត់ ឬអនុញ្ញាតពួកវាដោយផ្ទាល់ពីទីនោះ។

តើត្រូវចាប់ផ្តើម Android ឡើងវិញដែរឬទេ ក្រោយផ្លាស់ប្តូរបញ្ជី?

ទេ។ AdAway អនុវត្តការផ្លាស់ប្តូរភ្លាមៗ ប៉ុន្តែកម្មវិធីដែលបានបើករួចហើយអាចបន្តប្រើការតភ្ជាប់ចាស់ និងឃ្លាំងសម្ងាត់របស់វា។ សូមបិទវាឱ្យអស់ (បង្ខំឱ្យឈប់ នៅក្នុងការកំណត់ Android របស់កម្មវិធី) ហើយសម្អាតឃ្លាំងសម្ងាត់របស់វា ប្រសិនបើពាណិជ្ជកម្មនៅតែបង្ហាញ។ ត្រូវចាប់ផ្តើម Android ឡើងវិញតែម្តងគត់ក្នុងរបៀប root ក្រោយបើកម៉ូឌុល systemless hosts របស់ Magisk។

តើអាចរកប្រភព hosts បន្ថែមបាននៅឯណា?

AdAway មកជាមួយការកំណត់លំនាំដើមដែលសមហេតុផល។ ប្រសិនបើអ្នកចង់បានបន្ថែម សូមមើលបញ្ជីប្រភព hosts បន្ថែមដែលថែទាំដោយសហគមន៍។ សូមបន្ថែមប្រភពឱ្យតិចតួច ព្រោះបញ្ជីធំពេក ឬត្រួតគ្នា អាចបង្កការទប់ស្កាត់ខុសដែលធ្វើឱ្យកម្មវិធីដំណើរការមិនបាន។

ហេតុអ្វីបានជាមាន fork នេះ?

AdAway ជាគម្រោងដ៏ល្អដែលមានប្រវត្តិយូរលង់ ប៉ុន្តែសកម្មភាពចេញផ្សាយ និងត្រួតពិនិត្យនៅគម្រោងដើមបានមានកម្រិតអស់មួយរយៈហើយ។ ការជួសជុលកំហុស និង pull request មួយចំនួនបានស្ថិតនៅបើកយូរ រួមទាំងបញ្ហាដែលប៉ះពាល់ដល់ស្ថិរភាពរបៀប VPN នៅលើកំណែ Android ថ្មីៗ និង ROM របស់ក្រុមហ៊ុនផលិត។ fork នេះមានដើម្បីរក្សាឱ្យគម្រោងនៅតែប្រើបាន ជាមួយការជួសជុលដែលថែទាំដោយសហគមន៍ ជាជាងទុកឱ្យការកែលម្អដែលបានសាកល្បងហើយនៅទំនេរ។
