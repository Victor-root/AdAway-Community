La VPN se desactiva sola

Casi siempre se debe a que el sistema detiene el servicio de VPN para ahorrar batería, no a un fallo. Es habitual en las ROM de fabricantes con una gestión de energía agresiva (ColorOS/Oppo, MIUI/Xiaomi, EMUI/Huawei, One UI/Samsung y otras).

En los ajustes de Android, busca AdAway y haz lo siguiente: establece la optimización de batería en Sin restricciones (o en No optimizar), permite el inicio automático o autoinicio si tu ROM lo ofrece y bloquea AdAway en la lista de aplicaciones recientes para que no se cierre al deslizarlo. Comprueba también que Activar al iniciar está activado en las preferencias de VPN de AdAway.

Sin internet o con navegación lenta justo después de cambiar entre Wi-Fi y datos móviles

Cuando cambia la red activa, hay que volver a crear el túnel para que el DNS se resuelva desde la nueva red. Si la navegación sigue sin funcionar, abre Preferencias › Bloqueador de anuncios mediante VPN › Restablecer VPN para volver a crear la conexión desde cero. Si vuelve a ocurrir, captura un registro de diagnóstico (más abajo) y notifícalo.

¿Cómo exporto un registro de diagnóstico?

Abre Preferencias › Bloqueador de anuncios mediante VPN › Registro de diagnóstico. Registra los errores y eventos recientes de la VPN (cambios de red, reconexiones, fallos), no tu historial de navegación, solo eventos técnicos. Permanece vacío hasta que actives Activar el registro de diagnóstico, justo encima. Usa Copiar o Compartir para enviarlo al notificar un problema. Consejo: usa antes Borrar registro de diagnóstico y reproduce después el problema, para que el registro sea más preciso.

Chrome sigue mostrando anuncios

Chrome puede usar su propio DNS seguro (DNS over HTTPS), que se salta AdAway. En Chrome, abre Configuración › Privacidad y seguridad › Usar DNS seguro y desactívalo. Lo mismo ocurre con el ajuste DNS privado de cualquier aplicación o del sistema. En modo VPN, AdAway puede cifrar el DNS por sí mismo: consulta ¿Qué servidores DNS usa la VPN? en las preguntas frecuentes.

Algunos anuncios siguen apareciendo, o una aplicación sigue mostrando anuncios

Puede que falte un nombre de host en tus fuentes, o que la aplicación incluya sus anuncios sin hacer ninguna solicitud. Abre el Registro DNS desde la pantalla de inicio para ver qué consulta la aplicación, añade los nombres de host sospechosos a tu lista de Bloqueados y comprueba que no deja de funcionar nada. Algunas aplicaciones también guardan los anuncios en caché tras descargarlos, así que borrar la caché de esa aplicación en los ajustes de Android puede ayudar.

Una aplicación dejó de funcionar al activar AdAway

Algunas aplicaciones se niegan a funcionar cuando se bloquea un nombre de host que necesitan. Usa el Registro DNS para averiguar qué nombre de host necesita la aplicación, añádelo a tu lista de Permitidos y la aplicación debería volver a funcionar. Las aplicaciones problemáticas conocidas aparecen aquí.

Falla la aplicación del archivo hosts (modo root)

Las versiones recientes de Android usan una partición /system de solo lectura, por lo que AdAway no puede escribir en ella directamente. Si usas Magisk, activa el módulo systemless hosts, reinicia y vuelve a aplicar. Si no usas root, cambia al modo VPN, que no requiere modificar el sistema.

¿Sigues atascado?

Notifica el problema adjuntando un registro de diagnóstico en https://github.com/Victor-root/AdAway-Community/issues.
