什麼是 AdAway Community？

AdAway Community 是 AdAway（Android 上的開放原始碼廣告封鎖器）由社群維護的非官方分支。它能在整個系統中封鎖廣告和追蹤器，對所有應用程式都有效，不需要帳號，本身也沒有任何廣告。這個分支的重點，是讓應用程式在新版 Android 和各家廠商的 ROM 上持續穩定運作。

它是如何封鎖廣告的？

AdAway 有兩種運作模式：

VPN 模式（不需要 root）：AdAway 會在裝置上執行本機 VPN，你的流量不會被送到任何地方。它只檢查 DNS 要求，並攔截指向廣告和追蹤器主機名稱的要求，其他要求則一律放行。所有資料都不會離開你的裝置。

root 模式：如果你的裝置已 root，AdAway 也可以改為將 hosts 檔案寫入 /system/etc/hosts，把不想看到的主機名稱對應到 127.0.0.1，讓它們解析到你自己的裝置。在新版 Android 上，需要搭配 systemless hosts 模組（例如 Magisk）。

VPN 使用哪些 DNS 伺服器？

在 VPN 模式下，沒有被封鎖的主機名稱會由你在偏好設定 › VPN 模式廣告封鎖器 › DNS 伺服器中選擇的 DNS 伺服器負責解析：

網路 DNS 伺服器（預設）：使用你的 Wi-Fi 或行動網路提供的伺服器。如果網路沒有提供 AdAway 可用的伺服器，就會改用 Cloudflare（1.1.1.1）。
自訂 DNS 伺服器：使用你輸入的 IP 位址，並以逗號分隔。
DNS over HTTPS：要求會經過加密，並傳送到 Cloudflare、Google、Quad9 或你輸入的 https:// 位址，因此你的網路無法讀取或竄改這些要求。

這三種方式的封鎖效果都相同。如果想使用加密的 DNS，請在這裡選擇 DNS over HTTPS，而不要使用 Android 的私人 DNS設定，因為它會繞過 AdAway。

如何封鎖、允許或重新導向某個主機名稱？

你可以在主畫面管理三份清單：

已封鎖：要封鎖的主機名稱（廣告和追蹤器）。
已允許：你絕不想封鎖的例外項目，即使某個來源將它們列入也一樣。
已重新導向：你想指向特定 IP 位址的主機名稱。

你也可以在主畫面開啟DNS 記錄，即時查看各應用程式正在查詢哪些主機名稱，並直接在那裡封鎖或允許它們。

變更清單後需要重新啟動 Android 嗎？

不需要。AdAway 會立即套用變更，但已開啟的應用程式可能仍會沿用原有的連線和自己的快取。請將它完全關閉（在該應用程式的 Android 設定中選擇強制停止），如果仍然出現廣告，再清除它的快取。只有在 root 模式下，啟用 Magisk 的 systemless hosts 模組之後，才需要重新啟動一次 Android。

哪裡可以找到更多 hosts 來源？

AdAway 已內建一組合理的預設來源。如果你想要更多，請參閱由社群維護的其他 hosts 來源清單。請節制地新增來源，因為過大或內容重疊的清單可能造成誤判，導致應用程式無法使用。

為什麼會有這個分支？

AdAway 是一個歷史悠久的優秀專案，但上游的版本發布和審查已有一段時間不太活躍。部分錯誤修正和 pull request 長期處於未處理狀態，其中包括影響新版 Android 和各家廠商 ROM 上 VPN 模式穩定性的問題。這個分支的目的，是用社群維護的修正讓專案維持可用，不讓已測試過的改進被擱置。

如何回報錯誤或提出修改建議？

請到這個分支的問題追蹤頁面提出 issue：https://github.com/Victor-root/AdAway-Community/issues。回報 VPN 問題時，附上診斷記錄（請見「疑難排解」分頁）會很有幫助。
